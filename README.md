# amplUSB
Simple DIY stereo speaker project built on a perfboard using a PAM8403 amplifier, USB-C 5V power, and a 3.5mm jack

# Source component:
1:USB-C Connector (female) 

2:PAM8403

3:Female port jack

4🔈speakers 3W
